- 三平台源码和实际安装包专项见[平台验收](agent-desktop-platforms-plan.md)；普通签名提交及 Java 8／17 证据见[桌面可靠性](desktop-reliability-plan.md)。

- Beta.3 正常 GUI 启动已确认构建身份写入生产 D1，记录为维护自测；细节和未验边界见[构建身份验收](../design/telemetry-build-identity.md)。CLI／MCP 不新增默认遥测。
- #121 Fedora 实际渲染问题与 #151 图片资源回编译个例尚未确认解决，不列为修复；本轮未发现由 Beta.3 新增改动引入的阻塞证据。这不代表所有设备、用户 APK 或 Agent 宿主均已通过。

## 正式产物验收边界

版本同步后的 GUI 后端单测、发布脚本回归、Rust 格式、前端类型与 lint、文档本地链接及两份锁文件的离线一致性检查通过；真实环境专项保持原忽略设置，不计作通过。锁文件经逐项对比仅改变本项目版本，不含依赖升级。

正式版本重新构建，不能用 Beta.3 的包摘要代替；须核对正式包内 GUI／CLI、双壳和辅助 JAR 的完整版本及摘要，不含测试 APK、证书、数据库或本机配置。macOS 抽验使用完整 `.app`、自有源码夹具和隔离资料库，不改真实证书或全局 Java，不把版本首次上报当成自然用户升级。

未受影响的 Android 设备矩阵、其他 Java 和平台业务沿用上述既有证据；三平台构建成功不等于 Fedora 实际渲染、Intel 本机运行或全部 GUI 交互通过。若正式包核对发现阻塞，停止公开并修复，不悄悄覆盖已公开产物。
