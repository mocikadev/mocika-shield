# 桌面兼容与签名可靠性维护

更新：2026-11-12。稳定版保持 1.4.3，1.5.0-beta.1 已公开；本轮是后续维护候选，不改版本号或移动公开标签。

## 范围与边界

保持可审计、本地离线的加固链路，不引入闭源保护组件、第三方运行时遥测或在线取钥。统计接收记录可能来自不同构建，不能把服务端接收总量直接解释为本项目用户。没有可验证来源的历史记录不删除、不重新归属。

三个独立职责：维护脚本和只读 SQL 解释统计，GUI 启动模块处理 Linux WebView 兼容，共享核心管理普通签名产物。沿用现有库和 Java 参数适配，不新增服务、依赖、界面选项或数据库字段。

## 验收与发布

按阶段执行轻量测试，集中形成一个维护 PR。Rust 编译使用同一目标目录，避免复制多套缓存。GUI 本机交付必须是完整 `.app`；Linux 编译和策略测试不替代 Fedora 实际渲染验证。既有基础快速检查补充仅依赖标准库的 Linux 启动策略测试，不新增 CI 作业、重型任务或发布工作流；是否发布下一候选包待整批验收后决定。

普通签名的多文件提交提供可回滚的失败保护，不宣称跨文件原子事务或抵御同权限进程并发替换目录；进程崩溃／断电也不等于已经执行回滚。

本机结果：130 项脚本测试、核心 256 项常规测试及核心／CLI（含 MCP）严格 Clippy、GUI 编译检查通过。Java 8／17 的普通适配签名、Java 17 的显式适配与原工具签名通过，覆盖中文材料、覆盖／原地、V4 附件、提交前取消、失败保留、独立验签及 SDK 对齐。Agent 默认／编号真实签名复验通过，内部提交复核不增加或重复既有协议阶段；条件忽略的其他专项不计通过。两个聚合 SQL 已在生产 D1 只读验证，没有部署 Worker 或修改原始记录。
