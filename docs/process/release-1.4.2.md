## 验证边界与发布判断

- 本轮是正式交付前最小收尾，不重跑系统矩阵、不要求工控用户重复验收。rc.3 在 Android 4.4／6.0／10.0／11.0 的用户结果继续有效，但不改写为 rc.4 新壳完整矩阵实测。
- 后续壳类名、JNI 与 Manifest 专项的真机 32／64 位、覆盖、缓存、安全策略和 16 KB ARM64 证据见[字段治理记录](../design/manifest-runtime-contract.md)，新壳 Android 4.4 未重新实测边界保留。
- Windows 原生中文签名识别的个别反馈仍按维护者此前决定暂缓，不声称全部解决；Fedora 空白窗口仍待环境信息。这些现有边界不新设为正式发布阻塞。
- 输入夹具构建出现既有 Java 8 引导类路径警告，V1 证书检查提示夹具原有 META-INF 元数据不受 JAR 签名保护；V2/V3 与 ZIP 对齐均通过，不据此宣称无任何警告。

以上未发现本轮发布阻塞；已按授权公开 `1.4.2` 正式版，不增加功能或扩大支持范围。

发布差异已进行独立只读复核：版本与锁文件一致、依赖未变化；按复核意见保留资源代际兼容及 Windows 系统要求的双语说明。未增加功能或把新壳低版本未复测改写为通过。
