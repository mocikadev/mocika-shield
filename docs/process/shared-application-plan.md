# 多入口共享能力实施与验收

更新：2026-11-12。共享能力已随三平台 `1.5.0` 正式桌面包交付；`1.4.x` 不包含新增入口。架构见[共享应用设计](../design/shared-application.md)，用法见[共享资料 CLI](../ops/shared-data-cli.md)。

## 完成情况

| 范围 | 已实现 |
|---|---|
| 共享服务 | `shield-services` 承载本地目录、配置、证书和签名身份，不依赖 Tauri／clap／rmcp |
| GUI 回接 | 复用共享用例，前端只持无密码摘要；签名和指纹核对传证书 ID |
| 配置并发 | 稳定锁文件、锁内重读与字段补丁；保留未知字段，不回写过期全量快照 |
| 证书持久化 | 保留原目录、SQLite 表、ID 和 `enc:v1` 格式；有限忙等待，不持写锁运行 Java |
| CLI 管理 | 查询／导入／创建／校验／编辑偏好／默认项／删除记录；配置查询与显式保存 |
| 普通加固和签名 | 显式共享来源；与外部临时材料冲突时拒绝，不自动换证书 |
| 受控任务 | 记录级绑定、材料快照、执行前及提交前复核，不新增计划库 |
| MCP | 有限查询、受控加固、单次签名、偏好及证书生命周期管理 |
| Skill | 使用同一 CLI 与资料，不直接读取数据库、解密密码或保存机器路径 |

共享提取及后续能力由 #153～#158 合入；#159 将库名统一为 `shield-services`。旧名称只属于 Git 历史，不要求迁移用户数据。三平台后续结果见[平台验收](agent-desktop-platforms-plan.md)。

## 保持的契约

- 应用级偏好为 `config.toml`，证书及加密密码为 `shield.db`，新建证书默认位于 `keystores/`；不改应用标识和既有路径。
- 临时参数不隐式保存；普通加固只在明确启用共享时读偏好。项目 `shield-cli.toml` 是可选覆盖，不是另一套全局资料。
- 证书材料不可通过编辑替换；编辑只更新显示信息及签名偏好。CLI／MCP 删除只移除记录，保留文件。
- GUI 在下次查询、切页或恢复焦点时刷新；活动任务仍使用固定快照，不承诺实时推送。
- 共享绑定只覆盖选中记录和实际材料，不哈希整个数据库；切换默认项、修改无关记录不能使原任务换证书。
- MCP 沿用宿主启动时范围，能力共用不等于密码对模型可见。当前入口差异统一见[接入说明](../ops/agent-setup.md#当前工具与能力)。

## 用户名环境缺失兼容

早期 Agent 子进程缺少 `USER`／`USERNAME`，导致同一证书库的密钥派生上下文不一致。修复保留旧写入算法，只增加最多一个只读候选；Unix 当前账户查询有界，失败不猜账户，整条记录不能混用候选密钥。

验证覆盖有／无用户名交叉读取、旧密文写入兼容、坏格式／明文拒绝、错误 HOME／路径、原数据库字节及记录绑定不变。完整 macOS 应用内 CLI／MCP 在移除两个用户名变量后完成旧证书真实签名、独立验签及 SDK 对齐，没有重新导入或修改原证书。

## 真实资料库的桌面互通补测

2026-11-09，经维护者单独授权，在真实资料库中新增合成测试记录：

- CLI 创建后 GUI 可见；两边修改备注可互相读取。
- 维护者实际切离并切回 GUI，确认工控模式更新；GUI 改回标准模式后 CLI 读到相同结果。
- 临时证书与自有 APK 完成共享独立签名、独立验签及 SDK ZIP 对齐。
- 测试后恢复原业务偏好和默认项；原有证书摘要未变。经单独确认，只删除新增测试记录，保留证书文件；测试应用已退出。

该补测不等于 GUI 全流程或 Android 设备矩阵通过，也不要求后续测试默认读取真实资料库。

## 验收入口与限制

自动回归覆盖共享库、真实多进程并发、CLI 管理／签名／加固、受控绑定、MCP 和 GUI 配置刷新；真实 Java／完整应用包专项另行显式运行，忽略项不计通过。不要在同一 CLI 路径正被专项使用时原地编译替换它。

配置与 SQLite／证书文件不构成跨存储原子事务。新建文件后入库失败可能保留文件；回读或回执不确定须先查询，不自动重复创建或删除。旧版本同时运行不受新配置锁协议保护。

本地服务库不是后台服务；本次不实现 TUI、远程托管或 Android 运行时采集。
