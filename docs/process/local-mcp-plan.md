# 本地 MCP 实施与验收

更新：2026-11-12。MCP 已随三平台 `1.5.0-beta.1` 预览包交付；本文件保留初始实现决定和验收范围。使用与配置见[接入说明](../ops/agent-setup.md)，最新平台证据见[平台验收表](agent-desktop-platforms-plan.md)。

## 实现决定

- 同一 `shield` 增加默认关闭的 `mcp-server` 特性，桌面共包显式启用；使用锁定的官方 Rust SDK `rmcp 3.9.0`。
- 仅本机标准输入输出，不监听网络、不常驻、不随 GUI 启动。
- MCP 通过子进程复用 CLI，不把 SDK／异步类型或第二套执行规则带入核心。
- 启动时固定目录、资料来源与执行范围；默认只读，工具调用不能扩大宿主权限。
- 单个活动写任务；状态查询不争抢工作许可。未知结果或停止未确认后会话停写，查询保留。

## 已完成阶段

| 阶段 | 内容 |
|---|---|
| 只读接入 | 初始化、工具发现、环境检查、预检、规划；路径／参数／输出限制 |
| 受控执行 | 原计划摘要绑定、会话内限时引用、一次消费、进度、状态与取消 |
| 共享资料 | 脱敏查询、加固、单次签名、偏好和证书生命周期管理 |
| 完整交付 | 三平台 GUI 共包 CLI／MCP 和运行资源，Skill 独立分发 |

共享默认 5 项工具，启用执行后 15 项；外置兼容模式分别为 3／5 项。完整列表、参数与未开放项只在[接入说明](../ops/agent-setup.md#当前工具与能力)维护。

## 验收证据

最初在 macOS／Java 17 上，通过真实标准流客户端协商 `2025-11-25`，用自有约 641 KiB APK、临时证书和配置完成：

- 只读发现／拒绝执行、环境检查、预检及标准／工控规划。
- 规划到加固签名、独立验签、证书／摘要一致及 SDK 16 KB ZIP 对齐。
- 执行中查询、忙返回、重复执行拒绝、计划到期／漂移、输出占用和签名失败。
- MCP 取消、输入断开、超时及后代停止；输出背压另有组件测试，不冒充特定宿主按钮验收。
- 完整源码外应用包执行，输入、配置及包内资源不变，成功产物保留，取消无交付。

共享签名与证书管理的追加证据见[独立签名](controlled-signing-plan.md)、[管理](shared-mcp-management-plan.md)及[生命周期](mcp-certificate-lifecycle-plan.md)。Linux／Windows 实际安装包和后续源码专项见[平台验收](agent-desktop-platforms-plan.md)。

## 维护边界

- 计划开始尝试即消费；失败、取消或结果未知不能复活引用。状态仅在当前会话内保存，不提供跨连接任务恢复。
- 已知交付事实不能被晚取消或回执失败抹掉；丢失响应不等于未修改。
- 默认／特性测试不可并行覆盖同一 `target/debug/shield`；任务存活时不原地替换执行器或固定配置。
- 真实宿主的原生注册、自动发现、审批和取消按钮按需单独验证。标准流客户端通过不等于所有 Agent 已集成。
- 本机路径限制不是同权限恶意进程沙箱；不承诺完整 JDK 冻结、逃组或多重崩溃自动恢复。

实现结构见[本地 MCP 设计](../design/local-mcp.md)与[三平台设计](../design/agent-desktop-platforms.md)，不再沿用早期“仅 macOS、尚未共包”的状态。
