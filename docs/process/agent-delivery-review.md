# Agent 接入交付审查

2026-11-09 完成 macOS 共享能力收口；2026-11-11 三平台 `1.5.0-beta.1` 已公开。本文是审查结论，不是新的实施计划；当前平台与包级证据见[验收表](agent-desktop-platforms-plan.md)。

## 审查结论

- GUI／CLI 共享 `shield-services` 和同一资料库；MCP 通过 CLI 使用，不新增后台服务或第二套执行器。
- CLI 随 GUI 共包，Skill 由根目录 `skills/mocika-shield/` 独立分发；不修改用户全局 Agent 配置。
- 共享查询、受控加固、单次签名、偏好和证书生命周期管理已实现。入口差异只在[接入说明](../ops/agent-setup.md#当前工具与能力)维护。
- 共享能力由 #153～#158 合入，#159 完成共享库重命名；临时任务分支已清理，历史备份保留。

## 已处理的文档问题

用户说明曾按开发先后叠加，混用旧工具数量、外置材料和共享来源。已统一安装入口、最简配置、能力清单及任务示例，并将历史验证与当前状态分开。

三平台文档补齐命令路径、Windows PowerShell、Linux AppImage 稳定解包目录及 MCP 配置；普通用户不需要自行编译 CLI、另建证书库或再次输入已保存密码。

## 验收与未验边界

macOS 完整应用、当前 Agent 的显式 Skill 与标准流调用、真实共享证书签名已有记录。Linux／Windows 原生专项及实际安装包由后续[平台验收](agent-desktop-platforms-plan.md)补齐。

这些结果不证明每种宿主的原生注册、自动发现、审批／取消按钮均已验证，也不替代 Android 安装和业务回归。纯文档校准只核对引用、配置示例和实际接口，不重复未受影响的完整设备矩阵。
