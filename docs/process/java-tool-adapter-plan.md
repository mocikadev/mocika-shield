# Java 工具适配验收

设计契约见[Java 工具适配](../design/java-tool-adapter.md)；三平台产品和收口状态统一见[平台验收](agent-desktop-platforms-plan.md)。本页只记录工具层覆盖，不重复逐轮调试日志。

## 已完成

| 能力 | 已验证范围 |
|------|------------|
| 引导与请求 | Java 8／17、普通中文／空格工作目录、有限 UTF-8 帧、错误版本／长度／截断／尾随数据拒绝 |
| 私有材料 | Unix 权限、Windows ACL／身份、安全短名、缺失及改向拒绝；请求无密码 |
| 证书读取 | JKS／PKCS12、实际 Alias／主题／指纹、中文与补充字符业务路径、受信／Secret 条目及错误分类 |
| 证书新建 | 原 keytool 生成、实际材料复核、JKS 中文／分离密码、PKCS12 限制、无覆盖保存及入库失败保留 |
| APK 工具 | 固定 apksigner／apktool 入口、独立验签、解包／修改／重建、双流超量及错误输出 |
| 完整加固 | 标准／工控资源、签名绑定、Native 压缩策略、16 KB 对齐及阶段取消 |
| Agent 接线 | 适配 JAR 来源／副本绑定、篡改与材料错配拒绝；共享签名／标准加固、取消／超时／断开和后代清场 |
| Windows 普通入口 | 证书管理、普通签名／加固／验签及同卷写回；不是只验证显式测试入口 |

上述正式适配在本机与 Windows Java 8／17 的专项中验证；Windows 普通入口最近一次通过记录为[原生专项](https://github.com/mocikadev/mocika-shield/actions/runs/42992520650)。实际 GUI 安装包和各平台 Java 范围不得由此相互外推。

约 458 MiB 实际 APK 只做过本机 Java 17 的纯解包重建，不等同大包加固或设备运行证明。

## 回归入口

| 范围 | 用途 |
|------|------|
| 快速检查 | 普通 Rust／脚本测试、严格检查，不要求运行 Java 或生成 GUI 包 |
| 手动 `windows_paths` | Java 8／17 路径、证书内容及各工具返回／等待窗口的停止与故障 |
| 手动 `windows_protection` | 自有 DEX APK、固定双壳、显式完整加固与受控会话 |
| 手动 `windows_defaults` | 普通核心／CLI／证书入口及同卷／异卷行为 |
| 手动 `agent_bundles` | 实际安装包的资源、证书、双模式加固签名和 MCP |

不在每次提交运行这些重型专项；只在对应工具行为变化或交付收口时选择所需范围。CI 只用自有样本、临时证书及隔离资料库，不上传 APK、证书或资料库。

## 保留限制

- 补充字符**引导工作目录**仍在启动前拒绝；业务文本支持不等于工作根也支持。
- 无安全 ASCII 别名、路径或文件身份不能核对时失败，不改卷设置或换根重试。
- 真实工具已执行后的等待窗口通过，不代表 RSA／aapt2 算法内部、同步发布或数据库提交区间均可取消。
- 普通同步工具不承诺任意 Native 后代的通用硬期限；完整停止与无覆盖交付由 Agent 执行器承担。
- 安装包检查不替代 Android 设备、额外架构、文件系统或任意 JDK 提供程序的兼容验证。

遇到无法维持身份、停止、密码或保存规则的变化先停止并评审；回退整套桌面程序及匹配资源，不在失败任务里切回有损 argv。配置、证书密文和 Android 资源不迁移。
