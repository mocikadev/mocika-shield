# 1.4.0 正式发布记录

## 发布决定

2026-09-18 维护者明确授权从 Beta.6 直接发布正式版，不追加 RC 或人工验收前置任务；后续缺陷通过 1.4.1、1.4.2 等补丁版处理。基线为已发布的 `v1.4.0-beta.6`，只更新版本号、锁文件中的工作区版本和发布文档，不修改业务代码或第三方依赖。

## 证据与剩余风险

- Beta.6 三平台构建及 Release 发布成功，PR #126 已合并。
- 本地与远端测试证据见[分享回归记录](application-sharing-regression.md)及[上线记录](../ops/application-usage-sharing.md)，数据库无需重复迁移或部署。
- 尚未完成的真实 Tauri 人工交互、自动签名人工闭环及 Windows/Linux 原生运行保留原状，不冒称通过。
- #121 Fedora 空白窗口未定位，列为已知问题；#110、#116 功能建议不纳入本次发布。
- #117、#119、#120 已按修复/处理方案关闭；#2、#109 因缺少信息暂时关闭，不能据关闭状态推断用户验证成功。

## 执行任务

1. 同步版本到 1.4.0，保留 API19 独立锁，确认仅版本与文档变化。
2. 运行版本、格式、维护脚本和前端检查；形成一个发布准备提交，PR 必需 CI 通过后合并。
3. 从 main 创建新标签 `v1.4.0`，不移动 Beta.6 标签；仅生成三个平台 GUI 发布包。
4. 三平台构建成功后核对四类安装包、三份校验和及版本周期说明，将正式版草稿公开并设为最新版本。
5. 发生构建失败时保留草稿，定位后再处理，不带失败状态强行公开。执行链接与最终状态记录在发布 PR 中，避免为等待状态反复提交文档。
