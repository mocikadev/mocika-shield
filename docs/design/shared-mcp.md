# MCP 共享资料与证书范围

2026-11-09：维护者已确认采用宿主显式启用、固定应用上下文及证书编号白名单的方案。本文扩展[原本地 MCP](local-mcp.md)，不替代[受控共享绑定](shared-agent-binding.md)。源码已接入，实际测试与未覆盖范围见[共享应用计划](../process/shared-application-plan.md)。

## 选择与边界

采用显式共享模式，保留原外置配置模式。没有自动开放整库，避免把加固授权扩大为全部资料访问；也不保持另一套隔离产品状态或要求 GUI 常驻。本批只提供脱敏证书查询与共享受控加固。MCP 独立签名、证书导入／创建／校验／编辑／默认项／删除和配置保存均不开放，后续分别设计授权、目录及安全凭据入口。

Skill 可经已实现 CLI 使用上述管理能力，不等于 MCP 已有相同工具或写权限。不新增依赖、数据库、网络接口、后台服务、遥测、安装器或日常重型 CI；不修改壳、GUI 界面、公开版本或发布流程，不更改维护者真实库或全局 Agent 配置。其他平台仍后置。

## 宿主启动契约

```bash
# 路径及编号由宿主在本机确定，不照抄占位值。
shield mcp serve --use-shared-settings \
  --input-root /已授权输入目录 --output-root /已授权输出目录 \
  --allow-certificate <已保存证书编号>
```

- `--use-shared-settings` 显式启用共享来源；否则默认不读应用证书库。只有该模式允许 `--allow-certificate`，可重复指定，至少一项、最多 64 项且不能重复。编号限 1–128 位 ASCII 字母、数字或 `-_.`，不是路径或 Alias。
- 白名单启动后不可由模型更改，不代表已获任意执行许可；写操作仍须宿主 `--allow-execution`、本次用户授权及会话计划。
- 可选 `--app-home` 属于宿主启动配置，不是工具参数。缺省使用 GUI 相同目录，指定时固定隔离上下文；无效不回退，不能从请求换库。
- 共享模式可无项目文件；如宿主传 `--config`，继续固定其字节／物理身份，不接受混入外部签名材料。共享模式不向 CLI 子进程继承外部密码环境，不读值、不改全局环境或回退外部材料。
- 原模式保持原三项只读工具，执行仍要求固定项目及原密码环境。

共享上下文目录与输出目录不得互相包含。保留原路径用于密文兼容，不通过 canonicalize 改写派生上下文；仅核对目录身份、查找位置及文件形态，不固定整库／GUI 配置摘要。父目录改向、目录替换、资料文件变为链接／非普通文件时失败关闭。缺失资料保持缺失，查询不创建；同一固定范围内正常创建配置或更新 SQLite 不误判为材料改变。

## 工具及公开结果

共享模式新增只读 `shield_certificates`，可选 `certificate_id` 进一步筛选，未知字段及白名单外编号直接拒绝。复用 `cert list` CLI 和同一应用库，不在 MCP 复制 SQL、解密或写入逻辑。原摘要只在本地管道解析，经白名单过滤后才返回，不把整个 JSON 送给模型。

每条公开记录只有 `id`、`is_default` 和依次对应 V1–V4 的 `signing_versions` 四个布尔值；不含名称、路径、Alias、备注、校验说明或密码，不返回整库总数。缺失库／空库可返回空数组。保留现有 CLI 输出上限，过大或畸形响应失败关闭，不用通用数据库读取兜底。

共享 `shield_plan` 必须明确输入、输出及白名单 `certificate_id`，不能只说“以后用默认项”。可选 `runtime_profile` 没有默认值，省略时继承 GUI 共享模式；ABI 排除仍逐次授权。工具不接受配置路径、密码、Alias、绑定或环境变量名。

执行／状态查询参数保持原样：执行只收 `plan_id` 和原摘要，不接受新输入、输出、证书或绑定。只有宿主允许执行时才发现写工具，查询不授予加固或管理权限。

## 会话绑定与执行

CLI 返回版本 3 计划及绑定，MCP 复用 CLI 的严格解析，检查来源版本、白名单编号及原请求编号一致。绑定只留在本会话有限计划记录中；公开计划、执行响应及状态查询均移除 `shared_binding`，不要求模型回传它。断开／到期后不恢复，不新增计划数据库或全局一次性票据。

执行从已消费记录中取得绑定，经原 `agent protect` 处理。父端仍是唯一交付者，MCP 不重实现加固、签名或提交。默认项／GUI 模式变化不替换已有身份；相关记录或实际材料变化仍阻断。

原 16 条容量、10 分钟期限、一次消费、摘要不匹配不消费、开始尝试即消费、取消／断开／超时、未知收尾锁定及产物证据保留继续有效。执行结果的私有绑定须与缓存一致；旧来源必须返回版本 2，异常不换来源或自动重试。
