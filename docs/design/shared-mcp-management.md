# MCP 共享资料管理首批方案

2026-11-09，维护者已批准在既有共享加固／独立签名之上补齐资料管理首批能力。复用原宿主上下文、证书范围和执行开关，不新增确认、口令、计划或权限选项。公开稳定版保持 1.4.3，本批不发布。任务见[实施计划](../process/shared-mcp-management-plan.md)。

## 范围与工具

| 工具 | 能力 | 前提 |
|---|---|---|
| `shield_settings` | 查询共享业务偏好的模式、策略、自动签名意图及专用证书选择 | 共享模式 |
| `shield_update_settings` | 保存上述明确字段；其余配置保留 | 共享模式＋原执行许可 |
| `shield_update_certificate` | 修改允许范围内证书的名称、备注、V1–V4 及自动签名偏好 | 同上 |
| `shield_set_default_certificate` | 将允许范围内的明确编号设为全局默认，不改变加固页专用选择 | 同上 |

首批不接入导入、创建、校验、删除、清空全局默认、输出目录设置或任意配置。后续获准的创建／导入／校验／删除独立见[生命周期方案](mcp-certificate-lifecycle.md)，不将首批验收扩张到后续能力。偏好工具不会修改文件、Alias、密码或证书类型，不索要口令、不接收 SQL／程序／环境变量／资料目录。不增加后台服务、依赖、GUI 项或 CI 任务。

工具注解按 SDK 的实际含义填写：管理写入会覆盖已有偏好，不能假称只做新增；标记为写入且可能覆盖，不宣称可自动重试。注解不是新授权开关，服务自身不弹确认或要求前置计划；宿主原有的工具审批策略仍由宿主决定。

## 职责与数据流

架构为既有 MCP 入口内的局部扩展：工具参数模块映射固定 CLI，协议模块投影有限响应，运行模块管理调用与不确定状态。仍由现有 CLI `config show/set`、`cert edit/set-default` 和 `shield-services` 负责存储、锁及字段规则，不在 MCP 读取数据库或复制 SQL。保留原工具协议与加固计划绑定。

参数只接受有限类型；设置字段区分省略、设置、显式 `null`。`sign_after_protect:null` 恢复继承默认签名偏好，`certificate_id:null` 清除加固页专用选择，均不删除证书。模式使用保存值 `standard/android_api19`，策略为 `compatible/strict`。空补丁或未知字段直接拒绝，不隐式重置。证书文本有界并拒绝 NUL；所有字符串绑定为独立参数，编号可在 `--` 后传递，不能成为命令选项。

资料命令不带项目 `--config`，即使宿主固定了项目，也仍操作共享上下文；项目继续仅影响加固／签名调用。保存偏好不替换已固定的任务身份。默认项和备注变化不作废旧计划；相关签名版本变化仍由原绑定检查阻断，不能借管理工具绕过。

## 结果与未知状态

只读设置不返回输出目录、统计、界面字段或完整原配置。专用证书在范围外时隐藏编号，并明确标记范围外，不能伪装成未选择。证书修改回执仅返回编号、默认／版本／自动签名事实与已更新字段；不回显名称、备注、Alias、路径或口令。默认切换只确认目标编号。原证书查询投影保持不变。

新增写工具沿用同一个单活动调用门槛及未知停写标记，不新建管理计划、状态库或状态工具。明确成功返回 `change_state:confirmed`；CLI 明确未尝试写入返回 `not_attempted`。保存后回读失败、调用超时／断开、异常回执或无法确认停止时报告 `unconfirmed`，不称回滚，不自动重试，并禁止会话继续写入；查询仍可读取实际设置与允许项。已知结果不得因晚取消改写为“没有修改”。后台任务保留原收尾责任，不能因响应被放弃就丢失写入事实。

## 验收与交付

先做参数、投影和不确定状态单元回归；再用标准流真实进程验证设置字段保留、范围拒绝、元数据不改材料、默认项与专用选择分离，以及旧计划不被自动换身份。超时／坏回执验证不能误报未写入或继续写。

使用隔离资料和合成证书，不修改维护者真实库。最终重建完整 macOS `.app`，当前 Agent 直接连接临时 MCP 完成“读取→明确修改→单次签名→查询→恢复”，独立验签／对齐及资料回读通过；不以协议夹具冒充宿主原生工具注册。不重复未改动的 Android 系统矩阵，不机械发预发布版本，完整阶段集中提交。
