# 受控共享身份与无状态绑定

最后更新：2026-11-09。维护者已明确选择“无状态绑定参数”，不新增计划数据库或强制保存计划文件。本文承接[共享应用设计](shared-application.md)与[单任务契约](agent-cli-contract.md)；后者仍是当前已实现的外部配置接口。

当前状态：记录绑定、受控 CLI 共享来源、工作进程及提交检查已接入开发特性。Skill 0.2.0 已更新指引，MCP 按[固定白名单模式](shared-mcp.md)接入脱敏查询及共享受控加固。公开 Release 尚未更新；完整包、实际客户端和未覆盖范围分别记证，不据源码实现扩大声明。

## 为什么不能重新读取默认项或哈希整个数据库

当前 `agent plan` 与 `agent protect` 是两个独立进程，执行前重新规划。若第二次直接重新选择默认项，默认切换后可能选择另一张证书，或者让原计划无谓失效。若把 `shield.db` 当成普通配置文件整体哈希，改备注、写校验时间、创建其他证书都会误阻断。

已选方案：规划一次性解析本次证书与有效设置，返回不含秘密的绑定参数；执行回传该参数，并继续匹配原计划 SHA-256。不新增计划库、后台服务、端口或独立执行器。不采用强制保存本地计划文件，避免额外文件授权、清理及升级流程。

## 已实现：所选记录绑定

共享库 `certificates::store::binding` 提供：

- `capture_signing_identity`：同一个 SQLite 读事务解析默认项或明确 ID，读取原记录密文，生成绑定，再解密为本次材料快照。没有第二次选择默认项，不持读事务运行 Java。
- `BoundSigningIdentity`：内部材料和绑定，不实现 Serialize／Debug。空 Key 密码只在该快照中沿用 Keystore 密码，不改数据库。
- `CertificateBinding`：可序列化的非秘密对象，仅版本、证书 ID 和 32 字节状态摘要；字段私有，未知字段拒绝，未知版本不接受。它不是授权凭证。
- `check_certificate_binding`：只按绑定 ID 查询相关列，不解密密码、不启动 Java、不读取新的默认项。不查全库，不通过整个证书摘要反向复核。

摘要输入采用独立域标识、长度前缀字段和固定布尔字节：原数据库／托管目录身份、记录 ID、keystore 路径、Alias、类型、两项原始密文和 V1–V4 偏好。路径保持原密文上下文，不 canonicalize。绑定不使用明文密码或可离线猜测的密码摘要，也不把路径／Alias 输出到计划中。

排除名称、备注、创建／更新时间、校验状态／时间／说明、默认标记及自动签名偏好；已明确的受控操作是“加固并签名”，改自动签名偏好不撤销已有任务。全局默认项改变只影响下一次规划。签名版本的有效布尔值、路径、Alias、类型或密文改变则须重新规划；删除原记录不得回退其他记录。

记录绑定不读取 keystore 文件字节：外部文件变更必须由既有 `FileSnapshot` 检查。上下文不同的复制数据库不能复用同一记录承诺；这不等于密码迁移，也不是同权限恶意进程沙箱。修改后恢复到原状态的历史不在状态摘要证明范围内。

## 已接入：公共绑定参数

共享受控计划使用内部计划版本 `3`；原文件来源的计划版本 `2`、旧信封与旧命令默认行为保留，不以本次开发修改已经发布的格式。

绑定参数只携带：

| 字段 | 用途 |
|---|---|
| 绑定格式版本 | 拒绝未知或不完整格式 |
| `certificate_binding` | 已解析 ID 及所选记录承诺，不携带材料 |
| 运行模式 | 固定标准／工控资源选择 |
| 环境策略 | 固定兼容／严格策略 |
| V1–V3 版本及明确的 V4 关闭位 | 固定实际签名设置，不在执行时套用新默认 |

参数固定为 `--shared-binding`，由终态 `plan.shared_binding` 返回。使用规范 JSON 的小写十六进制编码，最多 4096 个 ASCII 字符（解码正文最多 2048 字节）；拒绝空串、奇数长度、非小写十六进制、尾随空白及非规范重编码。正文和记录绑定格式版本均为 `1`，证书 ID 最多 128 个 ASCII 字母、数字或 `-_.`；拒绝未知字段、错误类型、未知版本／枚举、无签名版本及 V4。`signing_versions` 固定为依次对应 V1–V4 的四个布尔值。不要自行构造或修改绑定参数。

```bash
shield agent plan --use-shared-settings -i input.apk -o protected-signed.apk
shield agent protect -i input.apk -o protected-signed.apk \
  --shared-binding '<上次终态的 plan.shared_binding>' \
  --expect-plan-sha256 '<上次终态的 plan.sha256>'
```

规划也可用 `--certificate-id` 或 `--use-default-certificate` 明确选择来源；`--runtime-profile`、`--environment-policy` 只在初次规划覆盖偏好。执行不得同时重新选择证书、模式或策略；ABI 排除须原样显式提供。`--app-home` 如使用，两次调用必须保持同一隔离上下文，不写进公开绑定。无任何共享参数的旧外置配置调用不隐式读取 GUI。共享来源拒绝外部密码环境与项目中的 keystore／Alias／类型材料；签名版本来自记录及可选项目覆盖，明确要求 V4 则拒绝。

完整绑定对象须纳入计划摘要。执行回传绑定和原 `expect-plan-sha256`，不得从失败响应中自动采用新摘要重试。绑定是可见参数，不是签名凭证、授权令牌、幂等票据或新的全局一次性数据库。

输入／输出仍须明确，单次 ABI 排除继续逐次授权。共享默认偏好在第一次规划解析；执行使用绑定参数，不因之后改变 GUI 模式、默认项或自动签名开关换证书或换策略。选定记录的相关材料／偏好或实际文件改变，仍要阻断。显式项目文件若提供，则其原有身份与工具覆盖继续绑定；共享设置不能扩大宿主权限。

## 已接入：工作进程和私有证据

父进程只管理期限、停止证明、源身份复核和最终提交；Java 仍全部在隔离工作进程。新共享入口不转调普通 `protect`，不牺牲已确认的取消、输出阻塞和未知停写语义。

本批按同一链路调整以下边界，没有以假配置占位：

1. 请求可没有项目文件；共享上下文由本机调用者／宿主固定，不允许 MCP 工具传任意数据库或环境变量名。
2. `Sources.config` 必须区分不存在的项目文件和有效项目快照；不能把 GUI `config.toml` 或 `shield.db` 作为替代的全量文件摘要，否则统计／无关证书更新又会误阻断。
3. 私有源证明增加共享上下文及绑定，仍不含密码。父端能只读核对选定密文列，无须解密或索取密码。
4. 无项目文件时，材料包只带输入、keystore、工具和资源。不能复制整个 GUI 数据库或生成明文密码 TOML。材料包须以明确版本表达可选项目角色；原六角色版本的缺项仍须拒绝，不能整体放宽检查。
5. 工作进程分别在规划／执行准备时检查记录绑定、实际文件身份和有效参数一致，再把原 keystore 复制为任务私有材料，保留原唯一提交者和停止证明。
6. 父端在开始执行、工作组停止后的验证、最终提交前最后检查点核对绑定和文件快照。先后检查总期限与取消；SQLite 的有限等待不是硬实时可中断保证。

共享启动描述版本为 `3`，源证明版本为 `2`，材料包版本为 `2`；外置配置分别保留 `2/1/1`。新版材料包在没有项目配置时固定五角色，有项目配置时固定六角色；旧版仍必须六角色，不能靠改版本或缺项跳过检查。父端同时核对请求与源证明的共享上下文、项目文件是否存在、角色及摘要；公开结果不直接透传私有证明。

规划后修改备注或其他证书不改变承诺；删除原证书、相关偏好或密文变更、文件换向／改写要阻断。默认切换不换证书。无关数据库文件字节变化既不构成材料改变，也不作为重试理由。

## 兼容、权限与停止条件

- 原外置配置受控分支及旧 `plan-protect` 继续拒绝新增共享字段；只有明确选择共享来源的 `agent plan/protect` 才能访问应用库。
- Skill 指引与 MCP 有限工具已按分项范围扩展；不向模型提供通用数据库／文件／环境读取或管理写工具。
- MCP 的根目录、证书允许集合、计划消费和状态锁定仍由宿主／会话管理。绑定不能扩大权限；允许加固不自动允许证书删除。
- 旧特性、外部环境密码与原计划匹配须独立回归。变化无法确认时不执行／不提交；不能通过自动重试、换默认项或重新生成计划掩盖问题。
- 不做数据库迁移，不改目录、密码格式、Android 壳、DEXB 或公开版本。CLI／GUI 仍共包，Skill 独立分发，不新增日常重型 CI。

## 分批验收

当前已完成：记录白名单、原子材料快照、无秘密模型、无关字段排除、多进程不误阻断，以及共享受控计划／工作进程／唯一提交者的链路接入。真实回归和限制按阶段记录逐项保留，不把普通命令或基础库测试代替新接口验收。

验收项目（各项实际结果与尚未覆盖的范围见阶段记录）：

- 绑定参数解析／严格往返、未知字段与超限拒绝、公共结果不含秘密／路径／Alias；旧文件来源结果不变。
- 默认项／共享默认设置变化后仍使用原计划；所选材料、实际文件或签名偏好改变则阻断；改名称／备注／校验及其他记录不误阻断。
- 准备、执行和提交边界均复核；保留原计划匹配、V4 拒绝、取消／超时／断开、输出占位、晚到取消、未知状态停写及无覆盖交付。
- 当前 Mac 自有真实 APK、源码外完整 `.app`、证书／对齐和原资料不变验证；其他平台、设备运行与宿主实际注册分别保留门槛。
