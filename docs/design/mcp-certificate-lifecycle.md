# MCP 证书生命周期管理

2026-11-09，在已合并的共享资料管理之上补齐证书校验、导入、创建和删除记录。仍限本机 macOS 开发接入，不发布新版本、不改 GUI、壳、密码格式或 CI。任务见[实施计划](../process/mcp-certificate-lifecycle-plan.md)。

## 工具与边界

四个新工具仅在原共享模式和原执行开关下提供，无新授权开关、前置计划或重复确认：

- `shield_verify_certificate`：按允许编号重新校验并保存结果，因此不是只读操作。
- `shield_import_certificate`：只接输入根目录内的相对 keystore 路径、名称、类型、可选 Alias／备注和签名偏好，默认保留原文件，不复制、不覆盖。单 Alias 可自动识别。
- `shield_create_certificate`：只接托管文件名、名称、Alias、主题及有限生成参数／偏好；目录由共享服务决定，同名文件按原规则另分配名称。
- `shield_remove_certificate`：明确编号即表达删除记录意图；内部复用 CLI 的确认参数，不再要求调用者输入第二次确认，证书文件始终保留。

保留原查询／加固／签名及资料工具。清空全局默认不在本批范围，避免误清范围外默认项；可通过已有默认切换工具选择明确允许项。删除默认记录沿用共享服务的默认处理，失效的专用选择不隐式换证书。

## 凭据和证书范围

导入、创建只从宿主启动环境预置的 `MOCIKA_SHIELD_KS_PASS`／`MOCIKA_SHIELD_KEY_PASS` 取得密码，不接受密码值、环境变量名、凭据文件或任意配置。仅这两种固定 CLI 调用继承该环境；已有共享签名、查询、校验和其他管理仍移除它们，不以宿主密码覆盖已保存材料。缺失时明确停止，不索要对话密码、不自动生成或猜测密码。更换预置密码需要宿主更新启动环境，不在工具中自改环境。

原有证书仍按宿主编号范围选择；允许初始范围为空，含义是没有旧证书授权，而不是允许全部。只有创建／导入的完整成功回执、参数核对及上下文核对均通过后，新增编号才进入当前服务会话的允许范围，可立即查询、签名及管理，不要求重启。此范围与原范围合计最多 64 项；达到上限在调用前拒绝新增。失败／坏回执／未知结果不得扩张范围，服务重启不自动允许此前新增项。删除成功后撤销该编号，旧任务仍由原身份和存在性检查阻断，不替换身份。

## 架构与结果

本批为既有 MCP 的局部扩展：参数层映射固定 CLI，协议层只投影编号、默认／版本偏好、校验状态或文件保留事实，编排层复用单活动门槛、桥接监督和未知停写。存储、密文、keytool、托管文件及默认规则仍由 CLI／共享应用库负责。无新 crate、依赖、数据库或第二套监督器。

导入前后核对输入根、普通文件及身份／摘要；链接、跳转、超限材料、目录和替换拒绝。共享服务有路径两端去空白语义，因此 MCP 拒绝会被该步骤改变的路径，不将校验与保存绑定到不同材料。不是对同权限恶意进程的完整隔离；导入保留路径后，未来材料漂移仍由已有身份校验处理。自由输入有界并按独立参数传递，不能注入选项。结果不回显路径、Alias、主题、名称、备注、密码或原始工具日志。

明确成功为 `confirmed`；明确未开始为 `not_attempted`；超时、断开、异常回执及保存后无法核对继续为 `unconfirmed` 并停止会话后续写入，查询可用，不自动重试或声称回滚。校验不通过但失败状态已明确保存时，回执为失败且修改已确认，不虚构校验通过，也不无故锁死会话；保存失败仍保守未知。创建失败可能保留文件，不自动删除或重试。

## 验收

分开验证严格参数／注入、范围新增与撤销、空初始范围、凭据只透传两类命令、脱敏回执、校验失败事实和未知停写；使用隔离资料验证真实创建／导入／校验／默认切换／签名／删除及文件保留。最终完整 `.app` 在源码外中文空格路径核对包内工具、双资源与签名，当前 Agent 直接标准流实调。不修改真实业务库、全局 Agent 配置或 Java 环境，不把临时连接等同宿主原生注册。
