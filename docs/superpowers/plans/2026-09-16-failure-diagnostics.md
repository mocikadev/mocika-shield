# 失败诊断实施与上线记录

1.4.0 Beta.5 阶段已完成；当前协议和部署见[设计](../../design/failure-diagnostics.md)与[运维](../../ops/failure-diagnostics.md)。1.4.2 已追加[有限诊断证据](../../design/error-report-evidence.md)，不能将首期 `evidence=[]` 当作当前全部能力。

## 交付内容

- 匿名失败原因只用固定枚举，按工具版本累计；旧客户端缺类别不伪造 UNKNOWN。
- 每份错误报告冻结发生时版本，由用户预览完整发送内容并确认；不上传日志、APK、包名、证书、密码或真实路径。
- 错误报告、匿名统计分开控制，不共享匿名安装标识；自动签名失败仍保留已完成的加固事实，取消不算失败。
- 服务端独立私有表、协议白名单、有界请求和原子限流；没有公开明细读取接口。

## 维护规则

报告正文由后端固定快照生成，前端只传报告编号和摘要；预览与发送字节必须一致。发送失败不自动重试，未知保存结果先查询。服务异常不影响原始任务，回滚先关闭新接收入口，保留数据库与旧通道。限额、保留期限和实际迁移顺序只在运维手册维护。
