# Manifest 兼容调查记录

历史方案（2026-08-25），不作为当前升级或发布指令。原计划拟评估 apktool 3.0.3，并验证较新的 Manifest 属性；当前仓库仍使用 `tools/apktool_3.0.1.jar`，不能将提案写成已交付升级。

## 调查目标

用户报告的异常缺少授权原始样本，因此用自建 APK 区分 Manifest 属性、apktool 处理和加固运行时问题。自建样本通过只能说明对应场景，不能证明已修复用户原包。

## 保留的验证要求

- 同一输入比较解包、重建后的 Manifest，不能删除属性或降低 targetSdk 来制造成功。
- 资源工具升级须核对实际 JAR 版本、所有查找／打包引用和完整应用包。
- 检查 MSHD、签名证书、Native 别名、Stored 库和 ZIP 对齐，设备验证与无设备测试分别记录。
- 工具问题未被证实时，不以升级版本替代样本定位，也不把 uni-app 的 Native／DEX 保护描述为前端资源加密。
