# 匿名统计按版本聚合实施记录

历史阶段：1.4.0。当前数据边界见[桌面统计说明](../../ops/telemetry.md)，维护口径见[项目统计](../../ops/project-statistics.md)。

## 已交付

- 客户端按 UTC 日期和完整工具版本保存累计值，失败阶段使用固定枚举，不发送错误原文。
- Worker 引入 `daily_usage_v2` 及固定阶段表；旧客户端和遗留数据保留，重复／乱序上传不重复累加。
- 趋势保留总量并增加版本和失败阶段；缺少分类的旧记录标为不可用，不补成零。
- 后续 1.4.0 Beta.5 增加失败原因分类和逐份确认报告，两者不能与阶段计数相加。

## 持续验证

客户端旧配置读取、版本分桶、关闭开关、取消、终态去重、上传失败和补传；Worker 协议白名单、幂等写入、真实 SQL 与新旧表合并；维护脚本缺字段和数据源失败隔离。

新旧表同时存在时，同匿名标识＋日期＋版本优先使用 v2；日活及 7／30 日活跃按窗口去重，当前规则以 Worker 和维护 SQL 为准，不沿用早期“总量相加”假设。

## 迁移边界

已有数据库只执行对应增量迁移，不删除、重建或回填遗留表。历史阶段的逐步测试预期和提交脚本已移除，部署按[失败诊断运维](../../ops/failure-diagnostics.md)及[项目统计](../../ops/project-statistics.md)执行。
