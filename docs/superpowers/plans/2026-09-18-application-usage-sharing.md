# 应用使用情况分享实施记录

1.4.0 Beta.6 起交付。交互、数据协议及保留边界以[设计](../../design/application-usage-sharing.md)和[运维](../../ops/application-usage-sharing.md)为准，不再重复接口清单与实现片段。

## 已完成

- 二进制 Manifest 身份解析与检查引用；前端不提交任意分享正文。
- 按可靠包名保存选择，加固／独立签名共用；新包名默认参与，同包名取消后持久有效。
- 任务快照绑定输入及选择，快速换包不消费旧响应；发送前再次核对当前退出偏好。
- 成功任务最多一份：自动签名不另计独立签名，失败／取消不分享。
- 独立发送队列、固定编号重试及有界超时；网络或偏好保存问题不改变业务结果。
- Worker 独立私有接收、严格字段／组合校验、真实 SQLite 幂等／冲突／限流和按服务端时间清理。

## 验收

后端、前端行为、Worker／SQLite 和两端共用载荷测试通过；自有普通 APK 完成标准／工控加固、独立签名、V1–V3 验签与内容检查。完整 macOS 应用构建和资源核对通过。

开发阶段人工界面未完成的项目保留在[回归记录](../../process/application-sharing-regression.md)，不把组合测试或应用构建当成 GUI 全流程已验。生产迁移与接收链路见[发布记录](2026-09-18-beta6-release.md)。

## 口径

分享不是匿名统计，不携带安装标识，也不与错误报告关联。按不同包名统计应用数不等于组织或使用者人数；加固与独立签名按各自操作去重，整体应用数取并集，不能相加。后续查询使用当前运维 SQL，不用开发测试数据解释线上使用量。
