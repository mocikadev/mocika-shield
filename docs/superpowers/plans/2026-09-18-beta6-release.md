# Beta.6 应用分享上线记录

历史发布：`1.4.0-beta.6`，已由后续 1.4.0 正式版承接；不是当前待推送／待打标签任务。

## 上线顺序与结果

2026-09-18 按授权先备份数据库并核对旧绑定，增量创建应用分享表／索引／触发器，再以新入口关闭状态部署 Worker。确认新路由 503，旧趋势、匿名统计和错误报告仍兼容后，配置独立限流密钥并启用。

真实接口验证首次／重复／冲突、非法／超限载荷、公开 GET 隔离及来源限流；全局上限只做本地 SQL 测试，没有向线上灌满。样本记录按专用编号清理，来源限流桶等待正常过期。

客户端版本、说明和本机门禁完成后，经 PR 合并与标签构建交付；当时未完成的 GUI／跨平台人工范围不由发布成功自动补成通过。

## 回滚与当前入口

异常先关闭 `APPLICATION_SHARING_ENABLED`，保留表、旧通道和用户记录。数据库恢复须另行确认范围，不能覆盖上线后的新记录。
