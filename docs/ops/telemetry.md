# 桌面统计、错误报告与应用分享

本工具有三个独立数据通道，控制方式不同；加固后的 APK 不包含这些上报，CLI／MCP 不增加默认联网采集。

| 通道 | 控制方式 | 发送内容 |
|---|---|---|
| 匿名使用统计 | 设置页开关，默认开启 | 随机安装标识、UTC 日期、工具版本、系统／架构、启动／加固／签名和固定失败类别计数 |
| 安全错误报告 | 每份预览并确认后发送 | 有限错误摘要、分类、精确步骤、路径布尔特征及可用环境版本；不含原始日志和应用包名 |
| 应用使用情况分享 | 加固／签名页选择，按包名记忆 | 应用名称、包名、版本码、工具版本、操作／流程、成功日期及协议去重信息 |

均不上传 APK、证书、密码或真实文件路径。关闭匿名统计不会自动关闭另外两个通道。

## 匿名统计

客户端按 UTC 日期和完整工具版本累计事件，启动时上传当天快照，加固／签名事件经过短暂防抖后同步。服务端同一匿名标识、日期和版本按累计值合并，重复或乱序请求不叠加成新事件。

从 Beta.3 起额外发送**桌面工具自身**的产品名称、应用标识和可用提交号，按来源分别累计，沿用同一统计开关；不扫描进程或读取安装路径。这不是用户 APK 的名称或包名，也不是官方来源认证。服务端已迁移和部署，官方 CI macOS 包正常启动已确认身份入库；Beta.2 和更早版本未包含。旧积压不补新名称，真实包验收与未验边界见[方案与实际进度](../design/telemetry-build-identity.md)。

当天成功上传的本地记录继续承接新事件；旧日上传成功后移除，未上传记录最多保留 30 天。网络、服务或额度异常不影响启动、加固和签名。

服务端从请求元信息保留当日首次有效的网络出口国家／地区代码，不保存原始 IP、省市或经纬度，不关联应用包名。地区日观察保留含当天的 90 个 UTC 日期，仅维护者可查询；历史补传不回填地区，代理出口不代表真实所在地。详见[地区统计](usage-country-statistics.md)。

统计只覆盖开启且成功上报的客户端，不能据此推算全部用户；境内网络可达性等因素会造成漏报。旧客户端没有失败类别信息时是“不可用”，不是零次失败。

## 用户确认的错误报告

报告在错误发生时冻结版本及有限诊断信息，用户逐份预览后决定是否发送；拒绝或关闭窗口不发送。报告不带匿名安装标识，不与应用分享关联；确认发送失败后不自动重试。

可诊断性补齐已随 1.4.2 交付，旧协议继续兼容。报告只保存于 D1 私有表，不进入公开趋势、维护历史或 Release 附件。字段、保留与查询见[失败诊断运维](failure-diagnostics.md)，技术边界见[错误报告设计](../design/error-report-evidence.md)。

## 应用使用情况分享

这是可识别应用的数据，不是匿名统计。新包名默认选中；取消对该包名持续有效，换版本、路径或重启不恢复选中，加固和独立签名共用选择。无法可靠识别应用时不分享，不影响原操作。

分享不带匿名安装标识或错误报告编号；仅维护者可查询，明细保留 180 天。取消停止后续发送，不自动删除已接收记录；公开展示案例须另行授权。详细字段、去重和删除说明见[应用分享运维](application-usage-sharing.md)。

## 服务与维护

数据由项目 Cloudflare Worker 写入 D1。公开趋势为有限汇总，不提供错误报告、应用分享或地区明细读取接口。

维护查询、统计口径和来源失败隔离见[项目统计](project-statistics.md)；数据库初始化、增量迁移和部署按各运维手册执行，不在用户隐私说明中重复建表命令。已有数据库不得依赖 `CREATE TABLE IF NOT EXISTS` 自动补字段。

维护者查看最新 Star／下载直接查询 GitHub，匿名使用趋势直接查询 Worker 或经授权查询 D1。采集失败明确标为不可用，不填零、不回填缺失历史，也不把所有接收版本自动视为本项目官方用户。
