# 匿名使用统计方案

Mocika Shield 默认开启匿名使用统计，用于了解实际启动、加固和签名使用情况。用户可以在设置中关闭统计。

## 数据范围

客户端按日期在本地累计启动、加固和签名次数，每台设备每天最多上传一条汇总记录。上传字段仅包含随机匿名 UUID、日期、应用版本、系统平台、CPU 架构和功能计数，不包含 APK、路径、包名、证书、密码或项目内容。

## 数据生命周期

当天数据不会立即上传。应用在后续日期再次启动时上传此前日期的汇总，所以上线页面至少延迟一天，并且需要用户后续再次启动应用。上传成功后立即删除对应日期的本地记录；上传失败的数据保留并在后续启动时重试；本地最多保留 30 天未上传记录。

## 服务端

数据通过 Cloudflare Worker 写入 D1 数据库。统计服务地址为：

`https://mocika-shield-stats-api.xuechao-suo.workers.dev`

统计服务异常、网络超时或额度耗尽均不得影响应用启动、加固和签名。

## 页面口径

GitHub Pages 展示的应用使用数据仅代表开启匿名统计并成功上报的客户端，不代表全部用户。

页面生成任务通过公开统计接口读取最近 14 天汇总，不需要把客户端密钥注入发布包。采集失败时页面会明确显示匿名使用统计暂不可用，同时继续更新 GitHub 下载与仓库指标。
